# Talia

Talia is a local conversational assistant that brings together Codex, spoken replies, and an animated 3D avatar.

## Capabilities

- Chat with Codex and see responses stream in real time.
- Start and revisit conversations, choose a model, and share a chat with readers and a writer.
- Hear replies generated locally with OmniVoice, using the default voice or an uploaded voice sample.
- See Talia's VRM avatar speak, react with expressions and gestures, and perform animations such as dancing or a backflip.
- Pause audio and control the avatar view, including opening it in a separate window.
